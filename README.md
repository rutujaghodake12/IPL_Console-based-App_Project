# IPL Console-Based Application 🏏

## 📌 Project Overview

The **IPL Console-Based Application** is a Java project developed to manage and retrieve Indian Premier League (IPL) player information through a console-based interface. It demonstrates Java programming concepts and database connectivity for accessing player records.

## 🚀 Technologies Used

- **Java** – Application development
- **JDBC** – Database connectivity
- **MySQL** – Database management
- **Eclipse IDE** – Development environment
- **Git & GitHub** – Version control and project hosting

## ✨ Features

- Retrieve all IPL players
- Fetch player information from the database
- Organize player-related operations using Java classes
- Connect Java applications with MySQL using JDBC

## 🛠️ Prerequisites

Before running the project, ensure you have:

- Java JDK installed
- Eclipse IDE
- MySQL Server and MySQL Workbench
- MySQL Connector/J library

## ⚙️ Setup and Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rutujaghodake12/IPL_Console-based-App_Project.git
   ```

2. Open Eclipse IDE.
3. Import the project using **File → Import → Existing Projects into Workspace**.
4. Configure the MySQL database and update the database connection details in the Java code.
5. Add the MySQL Connector/J JAR file to the project's build path.
6. Run the main Java class to execute the application.
